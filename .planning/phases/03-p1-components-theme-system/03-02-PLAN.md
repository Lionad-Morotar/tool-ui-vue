       ```css
       --spacing-12: 3rem;
       --spacing-16: 4rem;
       --spacing-20: 5rem;
       --spacing-24: 6rem;
       ```

    5. Inside the @theme block, add shadow variables (THEME-01):
       ```css
       /* Shadows */
       --shadow-xs: 0 1px 2px 0 rgb(0 0 0 / 0.05);
       --shadow-sm: 0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1);
       --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
       --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1);
       --shadow-xl: 0 20px 25px -5px rgb(0 0 0 / 0.1), 0 8px 10px -6px rgb(0 0 0 / 0.1);
       ```

    6. In the [data-theme="dark"] block, add dark-mode shadow values:
       ```css
       --shadow-xs: 0 1px 2px 0 rgb(0 0 0 / 0.2);
       --shadow-sm: 0 1px 3px 0 rgb(0 0 0 / 0.3), 0 1px 2px -1px rgb(0 0 0 / 0.3);
       --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.3), 0 2px 4px -2px rgb(0 0 0 / 0.3);
       --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.3), 0 4px 6px -4px rgb(0 0 0 / 0.3);
       --shadow-xl: 0 20px 25px -5px rgb(0 0 0 / 0.3), 0 8px 10px -6px rgb(0 0 0 / 0.3);
       ```

    7. THE-03 (consumer overridability) is inherent to CSS variables -- consumers override by redefining variables in their own CSS. Add a comment block at the top of the file explaining this:
       ```css
       /*
        * Theme tokens for @lionad
        *
        * Override any variable in your own CSS:
        *   :root {
        *     --color-primary: hsl(220 80% 50%);
        *   }
        *
        * Switch to dark theme:
        *   document.documentElement.setAttribute('data-theme', 'dark')
        */
       ```

    The final structure:
    - @import "tailwindcss";
    - Comment block explaining override mechanism
    - @theme { ... } block with light mode values (colors + spacing + radius + shadows)
    - [data-theme="dark"] { ... } block with dark mode overrides
