# Quick Task 260331-g0b: Approval Card 组件迁移计划

## 目标
将 Approval Card 组件从 React tool-ui 完全迁移到 Vue tool-ui，确保逻辑、功能、样式和类型定义完全一致。

## 差异分析

### 1. Vue 版本当前问题

**图标系统不一致**
- React: 使用 `getLucideIcon` 动态加载任意 Lucide 图标
- Vue: 仅支持硬编码的 5 个图标（check, x, link, trash, file-text）
- 影响: playground 使用 `icon: "check"` 无法正确显示火箭图标等

**Receipt 组件功能缺失**
- React: `ApprovalCardReceipt` 支持 `actionLabel` prop 自定义显示文本
- Vue: 仅根据 `choice` 自动显示 "Approve"/"Deny"

**按钮样式不完整**
- React: 按钮包含 `focus-visible:ring-offset-2` 样式
- Vue: 缺少该样式

**类型定义不一致**
- React: `ApprovalCardProps extends SerializableApprovalCard`
- Vue: `ApprovalCardProps` 单独定义，缺少 `onConfirm`/`onCancel` 类型

### 2. Playground 需要改进

当前 playground 仅展示基础用法，需要添加：
- Receipt 状态示例（approved/denied）
- Destructive 变体示例（Delete Project）
- 带 Metadata 示例（Send Email Campaign）
