## Pattern Applied

### Before (React-style):
```ts
// Test
const wrapper = mount(Component, {
  props: { id: '1', className: 'my-class' }
});

// Story documentation
| className | string | undefined | Additional CSS classes |
```

### After (Vue-native css object):
```ts
// Test
const wrapper = mount(Component, {
  props: { id: '1', css: { root: 'my-class' } }
});

// Story documentation
| css | { root?: string } | undefined | CSS classes for component elements |
```
