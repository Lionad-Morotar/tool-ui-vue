# Milestone v1.0: 多语言 i18n 系统

**Status:** SHIPPED 2026-04-14
**Phases:** 1-7
**Total Plans:** 31

## Overview

为 tool-ui-vue 组件库添加轻量级多语言 i18n 系统。26 个组件消除硬编码英文文本，zh-CN 为默认语言，en 为 fallback。零外部依赖，copy-paste 兼容。

## Phases

### Phase 1: I18N Core

**Goal**: 轻量 i18n 基础设施，provide/inject 模式，zh-CN 默认，en fallback，零外部依赖
**Depends on**: 无（首个 Phase）
**Plans**: 1 plan

Plans:

- [x] 01-01 — i18n core: types, composable, LocaleProvider, locales, exports

**Details:**
- 核心文件：types.ts（DeepKeyPath 类型系统）、use-i18n.ts（composable）、locale-provider/index.vue（SFC）
- zh-CN 280 键覆盖 23 个组件命名空间，en 镜像结构
- 零外部依赖：纯 Vue 3 provide/inject + computed
- {param} 插值、dev/prod 缺失 key 分支处理

## Milestone Summary

**Key Decisions:**

- 自研轻量 i18n 方案（零 vue-i18n 依赖），provide/inject 模式
- TypeScript DeepKeyPath 递归类型推导实现 t() key 自动补全
- vue-tsc ComputedRef 属性绑定问题通过 computed wrapper 解决
- vi.mock factory + shared locale state 模式统一组件测试
- Story 目录结构迁移 + key-based useStoryLocale 解耦

**Issues Resolved:**

- i18n subpath 类型声明缺失（core 多入口构建解决）
- ComputedRef 在 aria-label 属性中的类型不匹配
- 10 个组件 i18n 测试全覆盖（353 tests passing）
- zh-CN/en key 一致性 CI 校验

**Issues Deferred:**

- REQUIREMENTS.md traceability 表未同步更新（文档债务，实际功能已完成）
- Phase 5 的 checkbox 在 ROADMAP 中未全部勾选（显示问题，plans 已完成）

**Technical Debt:**

- REQUIREMENTS.md traceability 需要手动同步或自动化脚本
- lightningcss @theme warnings（ cosmetic，无功能影响）
