    需要适配 useI18n 的使用方式。

    1. 在 imports 部分添加：
       ```typescript
       import { useI18n } from '@lionad/vtu-core/i18n';
       ```

    2. 在 computed 区域添加（或在 setup 中如果使用 script setup 语法）：
       由于该组件使用 <script setup>，可以直接在 script 中调用 useI18n()：
       ```typescript
       const { t } = useI18n();
       ```

    3. 修改 spokenUnit computed（第 345-347 行附近）：
       当前:
       ```typescript
       const spokenUnit = computed(() =>
         props.unit === 'celsius' ? 'Celsius' : 'Fahrenheit'
       );
       ```
       改为使用 locale：
       ```typescript
       const spokenUnit = computed(() =>
         props.unit === 'celsius' ? 'C' : 'F'
       );
       ```
       （spokenUnit 仅用于 sr-only 文本，改为简洁的符号表示）

    4. 替换 sr-only 屏幕阅读文本（第 490-492 行附近）：

       ```html
       <span class="sr-only">
         {{ roundedTemperature }} degrees {{ spokenUnit }}
       </span>
       ```
       改为:
       ```html
       <span class="sr-only">
         {{ t('weatherWidget.srTemperature', { temp: roundedTemperature, unit: spokenUnit }) }}
       </span>
       ```

       - WebGL effect compositing（第 35-45 行引用的 effect-compositor）
       - 天气主题颜色计算（getWeatherTheme, getTimeOfDay 等）

       - 任何 CSS/glass effect 相关代码
       - 温度数字显示（°{{ unitSymbol }}）——符号 "C"/"F" 不需要翻译
