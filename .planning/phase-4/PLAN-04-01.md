# Plan 04-01: Shared Infrastructure for @lionad/core

## Goal

Move shared infrastructure from `src/shared/` to `packages/core/src/` so migrated components can import from `@lionad/core`:
- contract.ts - ToolUiContract pattern
- schema.ts - Shared schemas (ToolUIId, ToolUIRole, ToolUIReceipt, Action, etc.)
- parse.ts - parseX/safeParseX helper functions
- media/ utilities - aspect-ratio, format-utils, safe-navigation, sanitize-href, overlay-gradient

## Tasks

1. Create `packages/core/src/contract.ts` with ToolUiContract pattern
2. Create `packages/core/src/schema.ts` with shared schemas
3. Create `packages/core/src/parse.ts` with parseWithSchema/safeParseWithSchema
4. Create `packages/core/src/media/` directory with all media utilities
5. Create `packages/core/src/media/index.ts` barrel export
6. Update `packages/core/src/index.ts` to export shared infrastructure
7. Verify `pnpm --filter @lionad/core build && typecheck`

## Migration Pattern

- Keep all existing code unchanged (preserve exact functionality)
- Update relative imports to work within packages/core structure
- Export everything from main barrel file for tree-shaking

## Success Criteria

1. `pnpm --filter @lionad/core build` succeeds
2. `pnpm --filter @lionad/core typecheck` passes
3. All shared utilities importable via `@lionad/core`
