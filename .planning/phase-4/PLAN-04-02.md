# Plan 04-02: Migrate 15 Simple Components

## Goal

Migrate 15 simple components from `src/components/` to `packages/components/src/`:
- approval-card, audio, citation, code-diff, image, instagram-post, link-preview
- linkedin-post, message-draft, order-summary, plan, preferences-panel
- progress-tracker, terminal, x-post

## Migration Pattern (for each component)

1. Copy entire directory from `src/components/{name}/` to `packages/components/src/{name}/`
2. Update imports:
   - `../../utils` → `@lionad/core` (for cn)
   - `../../shared/contract` → `@lionad/core`
   - `../../shared/schema` → `@lionad/core`
   - `../../shared/media` → `@lionad/core/media`
3. Replace inline button/card/badge patterns with core components:
   - `<button class="...">` → `<Button variant="..." size="...">`
   - Container divs → `<Card>`, `<CardHeader>`, etc.
   - Badge spans → `<Badge variant="...">`
4. Update packages/components/src/index.ts barrel exports
5. Run existing tests to verify
