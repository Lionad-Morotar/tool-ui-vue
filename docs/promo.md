# 让你的 Agent 回复，也能赏心悦目

如果你正在开发一个 AI Agent，你可能会遇到这样的时刻：模型返回了一大段结构化的数据——餐厅推荐、旅行计划、代码 diff、社交动态——而你只能把它塞进一段单调的文本里，让用户在密密麻麻的字里行间自己找重点。

**tool-ui-vue** 就是为这个场景而生的。它是一个 Vue 3 组件库，专门帮你把 Agent 的每一次工具调用结果，变成看得清、点得着、交互自然的可视化界面。

## 为什么做这件事

我们相信，Agent 的体验不只是 "有没有答案"，更是 "答案好不好读"。当 Agent 帮用户预订餐厅时，一张带图片的轮播卡片比十行地址列表更直观；当它生成代码审查意见时，一段高亮的代码 diff 比纯文字描述更让人放心。

tool-ui-vue 的目标很简单：**让开发者只需要几行代码，就能给 Agent 穿上好看的衣服。**

## 它有什么不同

### 复制即用，不需要复杂配置

安装 `@lionad/vtu-components` 即可使用。组件自带类型定义和 Zod Schema，甚至自带了中文语言包——默认就是中文，不需要额外配置 i18n。

### 为 Agent 场景量身定做

库里的每一个组件都对应一种真实的 Agent 输出场景：

- 要展示餐厅、商品或视频推荐？用 `ItemCarousel` 轮播卡片。
- 要帮用户规划行程？`GeoMap` 地图上标出路线和景点，`Plan` 组件列出待办清单。
- 要做代码审查？`CodeDiff` 高亮增删行，`CodeBlock` 支持语法高亮和文件名展示。
- 要模拟社交动态？`InstagramPost`、`XPost`、`LinkedinPost` 直接还原平台风格。
- 要展示数据洞察？`Chart`、`DataTable`、`StatsDisplay` 一应俱全。

### 主题和国际化随你心意

基于 Tailwind CSS v4 和 CSS 变量构建的主题系统，让深浅色模式切换变得自然。而且，如果你需要支持双语，我们内置了完整的中英文 i18n 体系，切换语言只需一行代码。

## 适合谁用

- 正在用 Vue / Nuxt 搭建 Agent 产品的前端开发者
- 想让 LLM 输出从 "可读" 升级为 "好看" 的全栈工程师
- 需要快速搭建工具调用展示界面的独立开发者或小团队

## 快速开始

```bash
pnpm add @lionad/vtu-components
```

然后在你的 Nuxt 或 Vue 应用里引入主题 CSS，接着像使用普通组件一样使用即可。每个组件都支持通过 `v-bind` 直接绑定结构化数据，也可以细粒度地控制每一个子元素。

## 写在最后

tool-ui-vue 脱胎于真实的产品需求。我们自己在做 Agent 应用时发现，市面上缺少一套 "懂 Agent 语言" 的 Vue 组件库——不是通用的 UI 框架，而是专门为 "工具调用结果展示" 设计的原子组件。于是我们决定把它做出来，并且开源分享给大家。

如果你也觉得 "Agent 的回复不应该只是文本"，欢迎来试试 tool-ui-vue。有任何想法、建议或者想贡献的组件，都可以在 GitHub 上找到我们。
